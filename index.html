Единый формат файла «Фонд скважин»

Один лист, заголовок в строке 1, одна строка = одна скважина на одну дату. Ключ строки: Дата + № скважины. Все НГДУ и общий цех заполняют один и тот же шаблон.

Как данные доходят до единой картины

По рисунку с флипчарта: отдельные файлы (фонды) → папка → объединённый Excel → таблица, цвет, график. Читатели работают только с единым файлом.

Заполняют только НГДУ и общий цех (запись). Единый файл собирается одним действием; права «запись» / «только чтение» на сервере и способ синхронизации — нужно подтвердить. Эта страница не отправляет файл на сервер сама: результат скачивается и кладётся в общую папку.
